# 旧ステージコード

このディレクトリは、見下ろし操作への書き換え前の C++ コードを保存したものです。
`LegacyGameCode.vcxproj` は旧コードを静的ライブラリとしてコンパイルします。
`DirectXGame.sln` をビルドすると、現在のゲームと一緒にビルドされます。

旧コードは現在の `DirectXGame.exe` にはリンクされず、ゲームからも起動しません。
旧ステージ用のルート直下のファイルはビルド対象ではありません。旧コードを編集する場合は
このディレクトリ内のファイルを編集してください。
旧機能を再利用する際は、このディレクトリで変更・ビルドしてから、現在の
`GameScene` や `Player` へ必要な処理を移してください。
